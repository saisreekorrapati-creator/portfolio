Portfolio Setup & Mobile Fixes
Action: Launched my first site using GitHub Pages and customized a three-card layout for my landing page.

Struggles: I had a major issue with the cards cutting off on mobile screens. Even after clearing the cache, they wouldn't stack. I had to learn how to use a meta viewport tag and flex-wrap to make the layout actually responsive.

Learned: How to troubleshoot CSS on mobile using the browser's Inspect tool and the importance of "cache-busting" by renaming files when the phone refuses to update.
